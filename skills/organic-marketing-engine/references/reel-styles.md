# Reel styles and the content mix

Name styles by these names only. Never name the creators a style was studied from, in files, captions or chat.

| Style | What it looks like | Cloud-only? |
|---|---|---|
| Spotlight | Face on screen all the time, punch-ins or split cards on the top half, small captions in a black pill, one big serif-italic phrase per beat | Needs an editor pass |
| Straight Talk | One take, a framework or list, huge caption words, a named guide as the CTA | Plain render works |
| Scorecard | A persistent title bar, ratings and comparisons, proof cards | Needs an editor pass |
| Orbit | Face-cam with minimal UI floating around the head, one highlighted caption word, a first-person result hook | Needs an editor pass |
| Hot Seat | An audience-question sticker as the hook, one brand colour everywhere, decision cards, script-italic key words | Needs an editor pass |
| Tier List | Face on the top 55%, an S/A/B/C/D board below, a pinned "Ranking …" title, items dropping into tiers, the surprise saved for last | Avatar face + generated board |
| Whiteboard | Writing a framework live on a flipchart, with floating UI chips | The owner films it |
| Two Hands | Holding a prop in each hand, a "Good vs Bad (<audience> edition)" title, green/red pills by each hand | The owner films it |

Rotate styles so no style runs 2 days in a row.

## Content mix (per 10 posts)
- **4 AI and systems**, always with a comment-keyword guide
- **3 leadership, mindset or business**, with a guide only where there is a real resource
- **2 personal story or behind-the-scenes**, which build trust
- **1 quote or one-line truth**

Never post two technical reels back to back. A progressive series (each reel building on the last) builds authority faster than random topics.

Status: **Starter.** This comes from a study of 40 recent posts by creators in one niche: keyword reels drew the most comments, personal clips the most plays, and quote posts the most likes. It becomes a method rule once it's proven on 2 businesses (see SKILL.md → Adding what works).
