## Before you start (one time, about 10 minutes)

1. **Your SaaS Universe sub-account connector** must be connected in Claude: the MCP for *your* sub-account. Everything (guides, flows, contacts, pipelines) is created there.
2. **Instagram:** in your sub-account, go to Settings → App Store → Instagram and connect with **Instagram Login**, allowing every permission. It must be a Business or Creator account.
3. **Composio** (organic engine): connect your brand's Instagram. It's used to publish carousels and read insights.
4. **Meta Ads** connector (lead-form ads), plus the sub-account's Ad Launcher → Platforms → Connect with Meta.
5. **Slack** (optional): for reports.
6. **Claude in Chrome** (optional): lets Claude build the instant form in Ads Manager. Without it, Claude gives you the click path.

See `CONNECTORS.md` for the full list.

## How it works

Each playbook runs in the same order: **intake → readiness audit → build → live test → schedule or launch → reports**. Claude stops and tells you what to fix if anything isn't ready. Nothing paid goes live without your explicit "go ahead".

## Install

- **Cowork / Claude desktop:** open the `.plugin` file and accept it.
- **Claude.ai skills:** upload each folder under `skills/` as a skill (Settings → Capabilities → Skills).
